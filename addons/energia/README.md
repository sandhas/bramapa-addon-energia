# energia

Tarifa residencial B1 convencional (R$/MWh sem tributos, média simples das concessionárias) e
capacidade instalada de geração (MW) por UF e para o Brasil. Dados abertos da ANEEL, ODbL-1.0.

Procedência, método, lacunas e como regenerar os CSVs: [README na raiz do repositório](../../README.md).
Os CSVs em `data/` são gerados por `tools/fetch_energia.py`; não edite à mão.
